# SatQuery AI — Multimodal Satellite Intelligence Dashboard

A modern, high-performance web dashboard built with **React, TypeScript, Vite, and TailwindCSS** for Earth Observation (EO) analysis, multimodal visual question answering (VQA), change detection, and optical-SAR sensor fusion.

---

## 👥 Team Integration Guide (Backend, ML, & Database)

This frontend is designed for seamless integration with your backend APIs, ML inference engines, and spatial databases. All integration touchpoints are isolated inside **`src/lib/`**.

---

### 🔌 1. Backend Team (FastAPI / Flask / Node.js)

#### ⚙️ Configuration Setup
1. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
2. In `.env`, set:
   ```env
   VITE_API_BASE_URL=http://localhost:8000/api/v1
   VITE_USE_MOCK_API=false
   ```

#### 📡 Expected REST API Endpoints

1. **`POST /api/v1/inference`** — Model Execution & Multimodal Query
   - **Request Body (JSON)**:
     ```json
     {
       "scene_id": "NEPAL-2026-01",
       "query": "Detect flood inundation perimeter",
       "task_mode": "Change Detection",
       "sub_task": "Answer question",
       "primary_sensor": "sentinel2",
       "secondary_sensor": "risat",
       "band_combination": "NDWI",
       "user_rois": [],
       "target_center": [85.123, 27.987]
     }
     ```
   - **Expected Response (JSON)**: See `AnalysisPayload` in [`src/lib/types.ts`](src/lib/types.ts).

2. **`POST /api/v1/upload`** — Custom Local GeoTIFF / Image Upload
   - **Form Data**: `file` (Binary GeoTIFF / JPEG / PNG)
   - **Response**: `{ "success": true, "rasterUrl": "...", "metadata": { ... } }`

---

### 🧠 2. ML & Computer Vision Team (PyTorch / SAM / VQA / Change Detection)

All ML inference types and response payloads are defined in [`src/lib/types.ts`](src/lib/types.ts) and connected via [`src/lib/api.ts`](src/lib/api.ts).

- **`executeMultimodalQuery(params)`**: Main entry point for model inference.
- **Model Output Contract (`AnalysisPayload`)**:
  - `answer`: Natural language text response generated by the VQA/LLM model.
  - `confidence`: Floating-point model confidence score `[0.0 - 1.0]`.
  - `groundedRegionsCount`: Number of spatial ROIs / polygons detected.
  - `metrics`: Dictionary containing `changedAreaKm2`, `changedPixels`, `ndwiShift`, `cloudCoverPct`, etc.
  - `trace`: Array of step objects (`TraceStep`) representing model processing stages for live trace streaming.

---

### 🗄️ 3. Database & Cloud Team (PostgreSQL / PostGIS / Supabase / GeoTIFF COGs)

- **PostGIS Polygon Mapping**: Bounding boxes and ROI vectors drawn by analysts map directly to `GEOMETRY(Polygon, 4326)` in PostgreSQL/PostGIS.
- **Cloud-Optimized GeoTIFF (COG) Tiles**:
  - Tile endpoint can be configured in `.env` via `VITE_TILE_SERVER_URL`.
  - Supabase client initialized in [`src/lib/supabaseClient.ts`](src/lib/supabaseClient.ts).
