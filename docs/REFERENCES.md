# References and Starting Points

These are important baselines/prior-art systems to read before claiming novelty.

1. **GeoChat: Grounded Large Vision-Language Model for Remote Sensing** (CVPR 2024), arXiv:2311.15826  
   https://arxiv.org/abs/2311.15826

2. **TEOChat: A Large Vision-Language Assistant for Temporal Earth Observation Data** (ICLR 2025), arXiv:2410.06234  
   https://arxiv.org/abs/2410.06234

3. **EarthDial: Turning Multi-sensory Earth Observations to Interactive Dialogues** (CVPR 2025), arXiv:2412.15190  
   https://arxiv.org/abs/2412.15190

4. **ChangeChat: An Interactive Model for Remote Sensing Change Analysis via Multimodal Instruction Tuning**, arXiv:2409.08582  
   https://arxiv.org/abs/2409.08582

5. **DeltaVLM: Interactive Remote Sensing Image Change Analysis via Instruction-guided Difference Perception**, arXiv:2507.22346  
   https://arxiv.org/abs/2507.22346

## Reading order

1. GeoChat – understand grounded single-image remote-sensing VLMs.
2. TEOChat – understand temporal EO dialogue.
3. ChangeChat / DeltaVLM – understand interactive bitemporal analysis.
4. EarthDial – understand broader multisensor/multitask EO dialogue.
5. Then design EvidenceFuse-RS around reliability gaps rather than duplicating the above systems.
